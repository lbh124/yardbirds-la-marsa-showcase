# Yardbirds La Marsa Showcase

Build a premium, modern restaurant website for a real restaurant called “Yardbirds” in La Marsa, Tunisia.

IMPORTANT:

This is a client demo. The website should look production-ready and polished, but DO NOT invent factual business information. If something cannot be verified, use a tasteful placeholder that is clearly easy to replace later.

BUSINESS:

Name: Yardbirds

Category: Restaurant

Location: 13 Rue Mongi Slim, Marsa 2078, Tunisia

Phone: +216 99 332 882

The main objective is to make a potential customer immediately understand what Yardbirds offers, see the food, find the restaurant, and contact/reserve easily.

DESIGN DIRECTION:

- Premium contemporary restaurant aesthetic.

- Strong visual identity.

- Dark, sophisticated base with warm neutral/light accents.

- Large cinematic food imagery.

- Elegant typography.

- Lots of whitespace.

- Smooth but subtle animations.

- Mobile-first and fully responsive.

- Do NOT make it look like an AI-generated template.

- Avoid excessive gradients, glowing effects, generic blobs, or unnecessary animations.

- Keep the interface fast and professional.
